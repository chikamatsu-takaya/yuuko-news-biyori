## 再現手順（新しい依存を入れずに再取得できる）

- npm: `pnpm licenses list --prod --json`（pnpm 11 の組み込み。`node_modules` が無ければ `pnpm install --frozen-lockfile --offline`）。
  - `--prod` は package.json の `dependencies` から辿った範囲。`output: "export"` の静的書き出しなので、実際に配布物（`out/`）へ入るのはブラウザ向けに束ねられた JS/CSS だけで、`sharp`・`playwright`・`@babel/*`・`caniuse-lite` などのビルド時専用パッケージは配布物に入らない（next の依存として列挙されているだけ）。
- cargo: `cargo metadata --format-version 1 --manifest-path src-tauri/Cargo.toml --filter-platform x86_64-pc-windows-msvc`
  - ルート crate から「通常依存（kind=null）」だけを辿り、proc-macro crate（コンパイル時のみ動き実行ファイルに入らない）を除いた集合を「組み込み対象」とした。build-dependencies・dev-dependencies は除外。
  - 参考: Windows 対象の解決済み全体（build/dev/proc-macro 込み）は 365 件。
